# Журнал изменений

## 2026-11-17 — Тёмная тема: проверка и правки цветов
- `src/App.jsx` — сохранённая тема применяется при старте приложения. Раньше `data-theme` ставил только `ThemeToggle` в «Настройках», поэтому после перезагрузки на странице задач тёмная тема терялась.
- `common.css` — тёмные варианты модалок (фон `--card-bg-color`, заголовок, крестик, разделители шапки/футера), подписей полей, текста подтверждения и `.btn-secondary` (были белыми).
- `TaskTable.css` — тёмные заголовки подгрупп (были светло-зелёные) и бейджи статусов (были пастельно-светлые).
- `Select.css`, `DatePicker.css`, `StatusSelect.css` — меню и календарь в тёмной теме получили фон #333333 с рамкой #4A4A4A (чуть светлее модалки, чтобы не сливаться), кнопки-поля выровнены по цвету с остальными полями (`--header-bg-color`), ховеры и подсветка выбранного — на тёмно-зелёном.

## 2026-11-17 — Кастомный календарь вместо нативного поля даты
